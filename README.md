# Egg_Net 🥚

### 一个从 0 开始的 C++ 神经网络搭建笔记

这只是一个出于**纯粹个人兴趣**而开启的小实验。

在这个项目中，我没有使用现成的深度学习框架，而是尝试只用最原始的 C++ 一行行还原神经网络的每一个零件。我的目标不是写出一个多么高性能的代码，而是为了在这个过程中，彻底弄懂矩阵运算、反向传播和链式法则背后的数学逻辑。之后也许会继续探索更新！

#### 已经实现的小零件

- **纯手工矩阵类**：自己实现了矩阵的加减乘除、转置以及 Hadamard 积。
- **底层网络层**：手动处理了线性层（Linear）和 ReLU 激活函数的逻辑。
- **反向传播**：基于微积分链式法则手动推导并实现了梯度下降更新。

#### 目前的进展

目前已经成功让这个“小蛋”网络学会了解决 **XOR（异或）** 非线性分类问题。虽然是个很小的问题，但看到 Loss 从瀑布般坠落到 $10^{-31}$ 的那一刻，确实感受到了底层代码的魅力。
